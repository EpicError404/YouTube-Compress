# 📥 YouTube Compress & Download

**YouTube Compress** is a lightweight, open-source Android application designed to download and compress YouTube videos and audio locally on your device.

## 🚀 Features
* High-quality video downloading (up to 720p) and MP3 extraction.
* Background queue management via Android WorkManager.
* Powered by `yt-dlp` and `FFmpeg` for robust performance.
* 100% local processing with no external data collection.

## 📦 Installation
1. Go to the [Releases](../../releases) page.
2. Download the latest `.apk` file.
3. Install it on your Android device (enable "Install from unknown sources" if prompted).

## 🛠️ Tech Stack
* Kotlin & Android SDK
* yt-dlp-android / FFmpeg
* WorkManager & OkHttp
